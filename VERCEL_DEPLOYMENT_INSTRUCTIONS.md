# Srey Wallet - Full Source Code Package for Vercel Deployment

This archive contains the complete, production-ready source code of **Srey Wallet Ecosystem** (React + Vite + Tailwind CSS + @twa-dev/sdk + Autonomous Monitoring Engine).

## 🚀 Instant Deployment to Vercel (Free)

1. Extract this ZIP file on your computer.
2. Go to [https://github.com/new](https://github.com/new) and create a new repository (e.g. `srey-wallet`).
3. Push or upload these files to your repository.
4. Go to [https://vercel.com/new](https://vercel.com/new) and click **Import** next to your repository.
5. Keep default settings:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
6. Click **Deploy**!
7. Within 60 seconds, you will receive your live, permanent HTTPS URL (e.g., `https://srey-wallet.vercel.app`).
8. Paste that URL into Telegram's **@BotFather** -> `/setmenubutton` to launch Srey Wallet directly inside Telegram!
